**Problèmes trouvés : 2 Medium, 5 Low**

2. ~~**AC mentionne "SS-XXXX", implémentation affiche `orderNumber` (SS-XXXX)**~~ **Résolu**  
   Décision produit : format **SS-XXXX** retenu. Spec (AC et story) alignée sur SS-XXXX.

### LOW

3. **Accessibilité : select Statut** [orders-list-content.tsx]  
   Le `<label>Statut</label>` n’est pas associé au `<select>` (pas de `htmlFor` / `id`). À corriger pour les lecteurs d’écran.

4. **Tooltip depositStatus** [orders-list-content.tsx]  
   Seule la valeur `deposit_received` est traduite en "reçu". Les autres (`no_deposit`, `pending`, etc.) s’affichent en brut. Mieux : mapper toutes les valeurs connues vers un libellé FR.

5. **Bouton "Voir le détail" sans action**  
   Le bouton œil n’a pas de navigation. Conforme au périmètre de la story (liste uniquement) ; à prévoir en story ultérieure si besoin.

6. **Pas de composant Select shadcn**  
   Utilisation d’un `<select>` natif. Conforme aux Dev Notes ("Si le projet n'a pas de DatePicker shadcn, utiliser…"). Aucun correctif requis.

7. **formatOrderDate**  
   Fonction locale au composant ; extraction dans un util partagé possible si d’autres vues affichent des dates de commande.
